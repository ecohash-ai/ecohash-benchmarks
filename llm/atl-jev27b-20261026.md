# JEV-27B decision and chat API benchmark

Measured on 2026-10-26 through the public Ecolink API model-instance endpoint for instance 1070. The served model name was `jev-27b`; the decision alias `jev-27b-decide` mapped requests back to that name. Each level used two warmups and at least eight measured requests. The decision p95 latency gate was 2.0 seconds.

## Decision single-pass scan

All 138 measured decisions succeeded. Throughput peaked at C=20 (`22.33` requests/s) while staying below the 2-second P95 gate. C=24 still returned every response, but its P95 rose to 3.06 seconds. These rates describe the tested model-instance endpoint and do not establish a platform-wide service quota.

## Chat completions check

The chat run used streaming through `/v1/chat/completions`. At C=1, all 8 measured requests succeeded over a 57.4-second window, but P95 TTFT was 2,815 ms and P95 TPOT was 38 ms/token. The harness stopped before higher chat concurrency because those values exceeded its medium-class gates. Output speed was 20.9 tokens/s and request rate was 0.14 requests/s.

This is a complete-answer latency check. It does not measure the single-pass decision route and is not comparable to the table above.

## Separate decide-only run

A separate decide-only run was retained in [capacity-api-decide-separate-run.txt](data/atl-jev27b-20261026/capacity-api-decide-separate-run.txt). It reached a maximum gate-compliant concurrency of C=4 at `8.16` requests/s, then stopped at C=5 after four remote disconnects raised the error rate to 37.5%. Those transient failures were not mixed into the accepted scan above.
